# IMAGE → PDF

> รวมรูปภาพเป็นไฟล์ PDF ได้อย่างง่ายดาย (Client-side & Local-only Image to PDF Converter)

แอปพลิเคชันเว็บสำหรับการแปลงรูปภาพเป็นเอกสาร PDF ในเครื่องของผู้ใช้แบบ 100% Client-side ปลอดภัย รวดเร็ว ไม่มีการส่งไฟล์รูปภาพขึ้นเซิร์ฟเวอร์หรือคลาวด์ใดๆ ทั้งสิ้น

---

## ✨ จุดเด่นและฟังก์ชันการทำงาน

- 🔒 **Local-only & Privacy First 100%**: ทุกขั้นตอนประมวลผลภายในหน่วยความจำของเว็บเบราว์เซอร์ ไม่มีการส่งข้อมูลรูปภาพออกนอกเครื่อง (Zero Server Upload)
- 🚀 **ไม่มีการจำกัดจำนวนรูปภาพ (No Artificial File Limit)**: นำเข้ารูปภาพได้ตามขีดความสามารถของ RAM ของอุปกรณ์คุณ
- 📱 **รองรับไฟล์จาก Apple iPhone (HEIC/HEIF)**: ถอดรหัสไฟล์ HEIC/HEIF ในตัวผ่าน WebAssembly/JavaScript Client-side Decoder
- 🖼️ **รองรับไฟล์ภาพครอบคลุม**: JPG, JPEG, PNG, WebP, BMP, HEIC, HEIF
- 📋 **การนำเข้าภาพ 3 รูปแบบ**:
  - ลากและวาง (Drag & Drop) ได้ทั้งหน้าแรกและพื้นที่ Workspace
  - เลือกไฟล์หลายภาพพร้อมกันผ่าน File Picker
  - วางภาพจากคลิปบอร์ดโดยตรง (`Ctrl + V` หรือ `Cmd + V`)
- 📄 **1 รูปภาพ = 1 หน้าเอกสาร PDF** ตามมาตรฐานสากล
- 🔄 **จัดลำดับและหมุนภาพอย่างอิสระ**:
  - ลากเพื่อสลับลำดับหน้า (Drag to Reorder) รองรับทั้งเมาส์และหน้าจอสัมผัส
  - ปุ่มย้ายหน้า/ย้ายหลังสำหรับการสั่งการผ่านคีย์บอร์ด (Accessibility)
  - ปุ่มหมุนภาพทีละ 90° ตามเข็มนาฬิกาต่อใบ หรือหมุนพร้อมกันทั้งชุด
  - ลบภาพทีละใบหรือล้างรูปภาพทั้งหมดพร้อมระบบแจ้งเตือนยืนยัน
- ⚙️ **การตั้งค่า PDF ละเอียดและยืดหยุ่น**:
  - **ขนาดกระดาษ (Paper Size)**: A4 (ค่าเริ่มต้น), A3, A5, Letter, Legal, Original (ตามสัดส่วนภาพจริง)
  - **การจัดวางหน้า (Orientation)**: Auto (ปรับแนวตั้ง/แนวนอนอัตโนมัติตามสัดส่วนภาพ), แนวตั้ง (Portrait), แนวนอน (Landscape)
  - **รูปแบบการวางภาพ (Placement)**: Fit (พอดีหน้า ไม่ตัดขอบภาพ), Fill (ขยายเต็มหน้ากระดาษ)
  - **ระยะขอบ (Margins)**: ไม่มีขอบ (None), ขอบเล็ก (Small), ขอบกว้าง (Large)
  - **คุณภาพไฟล์ (Quality)**: ขนาดเล็ก (Small File), สมดุล (Balanced - แนะนำ), ความคมชัดสูง (High Quality)
  - **ตั้งชื่อไฟล์ (Filename)**: กำหนดชื่อไฟล์เองได้ พร้อมระบบล้างอักขระต้องห้ามอัตโนมัติ
- 🎨 **Modern Charcoal & Amber Design System**:
  - โทนสีมืด Charcoal (#0f1113) สบายตา ตัดด้วยสีส้มอำพัน (Amber Accent)
  - Responsive 100% รองรับ Desktop, Laptop, Tablet และ Mobile (รวมถึงปุ่มสร้าง PDF แบบ Sticky บนมือถือ)

---

## 🛠️ สถาปัตยกรรมและเทคโนโลยี

- **HTML5 / Vanilla CSS3 / Modern JavaScript (ES6+)**: น้ำหนักเบา ไม่พึ่งพาเฟรมเวิร์กขนาดใหญ่
- **pdf-lib**: สร้างและจัดการโครงสร้างไฟล์ PDF ในหน่วยความจำเบราว์เซอร์
- **heic2any**: ถอดรหัสไฟล์ HEIC/HEIF บนเบราว์เซอร์แบบออฟไลน์
- **SortableJS**: จัดลำดับรูปภาพแบบ Drag & Drop ลื่นไหลบนทุกอุปกรณ์
- **Sequential Memory Pipeline**: ถอดรหัส, ประมวลผล และฝังภาพลง PDF ทีละหน้า พร้อมปล่อยหน่วยความจำ (Garbage Collection) ทันที เพื่อรองรับไฟล์จำนวนมากโดยไม่ทำให้เบราว์เซอร์ค้าง

---

## 🚀 วิธีการใช้งาน

1. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์รุ่นใหม่ (Google Chrome, Microsoft Edge, Safari, Firefox)
2. หรือรันผ่าน Local HTTP Server:
   ```bash
   npx serve .
   ```
3. เลือกหรือลากรูปภาพมาวาง แล้วกด **สร้าง PDF** เพื่อดาวน์โหลดได้ทันที
